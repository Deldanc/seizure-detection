Why did recall increase?The original 0.50 decision threshold was conservative. Lowering the threshold increases seizure windows classified as positive, reducing false negatives but increasing false positives.
Important distinctionThe 44.4% → 88.9% change belongs to this recall-tuning experiment. The main baseline evaluation above uses a different held-out split and reports 42.22% recall.

06 · RESEARCH NOTES
Window-level vs event-levelA positive 5-second window is not automatically treated as a separate seizure event. Post-processing merges nearby windows.
Threshold objective mattersThe threshold used for window-level F1 and the threshold used for event-level detection answer different evaluation questions.
Inference is separateNew EDF uploads use the live inference model artifacts and should not be presented as additional held-out test results.
NEUROGUARD · Research prototype · Inference output is not a clinical diagnosis.
